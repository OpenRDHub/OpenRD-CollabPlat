Project Background

罕见病社区面临的困境

7000+ 罕见病种

全球已知罕见病超 7000 种，中国约 2000 万患者，80% 无有效治疗药物

需求无处对接

患者有大量真实工具需求（用药管理、症状记录等），但缺乏技术能力

力量分散

社会有大量愿意参与公益的技术志愿者，但缺少有效组织方式

运营人力有限

从需求发现到项目落地严重依赖人工协调，不可持续

需要一个平台，把患者的真实需求和社会公益技术力量高效连接起来。
Our Solution

OpenRD — 让需求找到开发者

患者通过平台提交需求，开发者通过平台认领任务，实现罕见病问题的协作解决。

需求接单系统

需求者 ←→ 产品经理
提交需求 → 沟通评估 → 转化为任务

项目协作系统

产品经理 ←→ 共建者
发布任务 → 组队认领 → 协作开发 → 验收交付

业务主线：需求提交 → 产品经理评估 → 转化任务 → 任务大厅招募 → 组队开发 → 验收交付

Why We Need Support

公益项目的持续性难题

持续性支出

服务器成本每月产生，公益项目无商业收入来源

开发效率

团队分布各地，需要稳定线上环境联调、测试和演示

可靠基础设施

平台要服务真实用户，需要 7×24 可用、有公网 IP 的服务器

早期投入

公益技术项目在早期最脆弱，有基础设施保障才能吸引志愿者持续参与

没有资源支持

  • 本地开发，无法在线演示
  • 成员环境不一致
  • 无法积累真实用户数据
  • 负责人自费承担

有资源支持

  • 在线服务，随时可访问
  • 统一部署，高效协作
  • 可对接罕见病社区使用
  • 可持续、无后顾之忧
