**标题：** 公益项目的持续性难题

1. **服务器成本是持续性支出** — 不像一次性开发可以靠志愿者完成，运维费用每月产生，公益项目无商业收入来源

### 开场（第 1-2 页，约 2 分钟）

各位好，我是 OpenRD 罕见病需求项目协作平台的项目负责人王梓旭。感谢 Intel AI-Hub 和基金会给我们这次沟通机会。

先用一句话介绍我们在做什么：**我们在建设一个让罕见病患者能发布需求、让社会技术志愿者能组队完成开发的开源协作平台。**

简单来说，患者有痛点但没有技术能力，志愿者有技术能力但不知道帮谁。我们的平台就是连接两端的桥梁。

---

### 项目背景（第 2 页，约 2 分钟）

说一下为什么要做这件事。

全球已知的罕见病超过 7000 种，中国大约有 2000 万罕见病患者。这些患者面临的不只是缺药的问题——在日常生活中，他们有大量具体的工具需求：用药提醒、症状记录、就医信息整理、病友社区等等。

但患者和家属往往没有技术开发能力。与此同时，社会上有大量愿意参与公益的技术人员：开发者、设计师、产品经理。但这些力量非常分散，没有一个有效的组织方式把需求和能力匹配起来。

我们的社区运营团队人力也非常有限——从患者提出需求，到确认项目、招募成员、推进开发，以前几乎全部依赖人工协调。这不可持续。

所以我们决定做一个线上平台，把这整个流程自动化、结构化。

---

### 解决方案（第 3 页，约 2 分钟）

OpenRD 的核心设计是两套系统的结合：

第一套是**需求接单系统**。患者和家属在平台提交需求，平台内有能力的产品经理会主动评估、沟通，确认需求有效后转化为一份标准的任务工单。

第二套是**项目协作系统**。任务工单发布到任务大厅，技术志愿者可以浏览、申请加入队伍，由队长协调分工，协作完成开发，最终交付验收。

整个流程闭环是：需求提交 → 评估沟通 → 转化任务 → 任务招募 → 组队开发 → 验收交付 → 需求解决。

这类似于把需求端做成一个"公益版 Boss 直聘"，任务端做成一个"开源版项目管理平台"，两端通过产品经理连接。

---

### 角色与场景（第 4 页，约 2 分钟）

平台有四种角色。

**需求者**是患者或家属，核心行为是提交需求和跟踪进展。

**共建者**是技术志愿者，核心行为是浏览任务、加入队伍、参与开发。

**产品经理**是运营人员，负责评估需求、转化任务、跟进进度。

**超级管理员**负责用户管理、权限配置和安全审计。

举一个真实场景：小明今年 8 岁，患有罕见遗传病，每天要吃多种药物。妈妈一直用手写表格记录，经常忘记服药时间。她在平台提交了"药物服用提醒 App"的需求，详细描述了痛点。产品经理评估后认为需求明确，转化为开发任务。前端工程师小李在任务大厅看到这个项目，正好是他擅长的小程序开发，他申请加入。最终三人组队两周完成了开发，妈妈验收后非常满意。

这就是我们想让平台跑通的核心链路。

### 技术架构（第 7 页，约 1.5 分钟）

技术上采用前后端分离架构。

前端是 Vue 3 + TypeScript + Pinia + Vue Router，组件库自研保证长期 UI 一致性。

后端是 Python FastAPI 框架，ORM 用 SQLAlchemy 2.0，数据库选 PostgreSQL 18，缓存和消息队列用 Redis 7.4。

部署方案是 Docker Compose 容器化，Nginx 做静态托管和反向代理。整套技术栈都是主流开源方案，稳定可靠，对运维要求不高。

---

### 资源需求（第 8 页，约 2 分钟）

这次我们申请的资源很明确：**一台长期可用的云服务器**。

配置需求是：4 核 CPU、8G 内存、80G 硬盘，操作系统 Ubuntu Server 24.04 LTS，需要公网访问。不需要 GPU 或 AI 加速卡。

这台服务器会运行我们全部服务：Nginx、FastAPI 后端、PostgreSQL 数据库和 Redis，全部通过 Docker 容器管理。

当前阶段用户量有限，这个配置完全够用。我们的需求很务实——不是要高性能计算集群，而是要一个稳定、可靠、长期可用的部署环境。

### 为什么需要支持（第 9 页，约 2 分钟）

公益项目最大的难题是：**开发可以靠志愿者，但运维费用每月都在产生。**

服务器租用是持续性支出，商业项目有收入覆盖，但公益项目没有。目前这部分由项目负责人个人承担，这显然不可持续。

更关键的是：没有稳定的线上环境，整个开发效率都会受影响。我们的团队成员分布在不同城市，需要一个统一的在线环境来联调、测试和演示。而平台最终要服务真实的罕见病社区用户，需要 7×24 可用的服务。

早期的基础设施保障对公益技术项目至关重要——有了稳定环境，才能吸引更多志愿者看到成果、参与贡献、形成正循环。
