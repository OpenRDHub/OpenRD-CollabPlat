# OpenRD 文档目录

`docs/` 用于存放当前有效的产品文档和必要的文档索引。

## 当前正式文档

当前项目理解以以下文档为准：

```text
OpenRD协作平台PRD正式版.md
```

该 PRD 描述了罕见病运营管理平台的背景、目标、角色权限、核心业务流程、P0 功能清单、非功能需求、核心数据表和项目计划。

## 治理与 SOP 方案

项目运营、组织治理、二期子任务系统和开源项目开发 SOP 的讨论稿见：

```text
OpenRD开源协作治理与SOP方案.md
```
