# OpenRD 历史文档归档

本目录用于保存已经归档的历史产品资料、设计建议、早期 PRD、PDF 导出和 DOCX 文件。

这些文档可以用于追溯讨论过程和历史设计依据，但不再作为当前开发的主依据。

## 当前主依据

当前项目理解以父级目录中的正式 PRD 为准：

```text
../OpenRD协作平台PRD正式版.md
```

如果本目录中的历史文档与正式 PRD 存在差异，以正式 PRD 为准。

## 归档内容

本目录包含：

- 早期平台概念文档。
- 早期协作平台设计建议。
- 角色分类与工作台磁贴说明。
- 历史 PRD 模板和飞书导出文档。
- PDF / DOCX 格式的历史资料。
- 空白备忘录文件。

## 使用原则

- 需要理解历史讨论时可以查阅本目录。
- 编写需求、接口、前后端实现文档时优先引用正式 PRD。
- 不建议在本目录继续新增当前版本文档。
